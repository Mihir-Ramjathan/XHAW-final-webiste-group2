# Pawsitive Pet Academy — Website

## 1. Project Overview

Pawsitive Pet Academy is a pet care education and animal training business established by Sarah Smith in Durban in 2023.

This website was created as part of our Work Integrated Learning (WIL) group project. Its purpose is to help customers learn about the academy, view available courses, calculate course fees and request more information.

The website is designed to be simple, professional and easy to use.

## 2. Project Objectives

The main objectives of the website are to:

- Provide information about Pawsitive Pet Academy.
- Display the available pet care and training courses.
- Allow customers to select one or more courses.
- Calculate course fees and discounts.
- Allow customers to request quotations.
- Provide an enquiry form and contact information.
- Create a user-friendly website for desktop and mobile devices.

## 3. Technologies Used

**HTML5**

HTML was used to create the structure and content of the website, including headings, paragraphs, images, buttons, navigation links and forms.

**CSS3**

CSS was used to style the website. It controls the colours, fonts, spacing, layouts, buttons and responsive design.

**JavaScript**

JavaScript was used to add interactive features, including selecting courses, calculating discounts, validating forms and updating information displayed on the website.

**Visual Studio Code**

Visual Studio Code was used to create and edit the website files.

**Figma**

Figma was used to design the website wireframes and plan the layout of the pages.

**GitHub**

GitHub was used to store the project files and support group collaboration.

## 4. Website Pages

The website includes the following pages:

1. Welcome — Introduces the academy.
2. Home — Displays the main website information.
3. About Us — Explains the academy's background and purpose.
4. Courses — Displays the available courses.
5. Course Details — Provides more information about individual courses.
6. Select Courses — Allows customers to choose courses.
7. My Selection — Shows the selected courses.
8. Fees — Displays the total fees and discounts.
9. Request Quote — Allows customers to complete a quotation request.
10. Enquiry — Allows customers to ask questions.
11. Contact Us — Displays contact information.
12. Confirmation — Displays a confirmation after completing a form.

## 5. Available Courses

The academy offers seven courses.

**12-week courses — R1,500 each:**
- Canine Obedience Training
- Pet Grooming
- Animal Behaviour
- Pet Business Management

**6-week courses — R750 each:**
- Puppy Care
- Pet First Aid
- Basic Dog Walking

## 6. Course Discount System

Customers receive a discount based on the number of courses selected.

| Number of Courses | Discount |
|---|---|
| 1 course | 0% |
| 2 courses | 5% |
| 3 courses | 10% |
| 4 or more courses | 15% |

**Example:**

If a customer selects two courses costing R1,500 each:

- Subtotal: R3,000
- Discount: 5%
- Discount amount: R150
- Final total: R2,850

The website automatically calculates the discount based on the selected courses.

## 7. Website Design

The website follows a user-centred design approach. This means that the design focuses on making the website easy for customers to understand and navigate.

The main design features include:

- Simple and clear navigation.
- Readable text and headings.
- Consistent colours and buttons.
- Organised course information.
- Responsive layouts for different screen sizes.
- Easy-to-use forms.

## 8. How to Run the Website

1. Download or clone the GitHub repository.
2. Open the project folder in Visual Studio Code.
3. Open the welcome or home HTML file in a web browser.
4. Use the navigation menu to move between pages.
5. Browse courses, make selections and test the fee calculator.

The website uses HTML, CSS and JavaScript, so a separate application server is not required for basic local testing.

## 9. Project Functionality

The website allows customers to browse courses, select courses and view their total fees.

JavaScript is used to calculate the correct discount automatically.

The website also includes forms for quotation requests and general enquiries.

The current forms are demonstration features. They can display confirmation messages, but they do not send customer information to an online database or email service.

The website uses browser storage to help maintain course selections while navigating between pages.

## 10. Testing

The following features should be tested:

- Navigation links open the correct pages.
- Course information displays correctly.
- Courses can be selected and removed.
- Discount calculations produce the correct results.
- Forms check that required information is entered.
- Confirmation messages display correctly.
- The website layout works on desktop and mobile screens.

## 11. Project Limitations

The website is a student project and is not connected to a live booking or payment system.

Quotation requests and enquiries are currently demonstrations. A future improvement would be to connect the website to a database and allow the academy to receive customer requests.

## 12. Future Improvements

Possible future improvements include:

- Online course registration.
- Customer accounts.
- A database for storing enquiries.
- An online payment option.
- Email notifications.
- Additional course information and images.
